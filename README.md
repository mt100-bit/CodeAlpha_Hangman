# Hangman Game

## About the Project

This is a command-line Hangman game built with Python as part of my CodeAlpha Python Programming Internship tasks.

The game challenges players to guess a hidden word one letter at a time before running out of attempts.

## Features

* Interactive command-line gameplay.
* Accepts letter guesses from the player.
* Tracks guessed letters and remaining attempts.
* Provides feedback on correct and incorrect guesses.

## Technologies Used

* Python 3

## How to Run

1. Install Python 3 on your computer.
2. Clone this repository or download the project files.
3. Open a terminal in the project folder.
4. Run the following command:

   ```bash
   python hangman.py
   ```
